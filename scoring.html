📝 Separate from the alert system. This page is a logging and review surface only: it never chimes, never notifies, and a failure here cannot disrupt the replay feed's alerts. Everything shown was captured live, before the fact, from the official MLB StatsAPI — official wording is quoted verbatim.

Unofficial fan project. Live data via the public MLB StatsAPI (statsapi.mlb.com). Not affiliated with MLB or MLB Advanced Media. ⚑ Flagged for Review

What this page logs. (1) Official scoring pending — at bats whose official outcome is not yet decided, detected from the payload's own event type (os_ruling_pending_primary / os_ruling_pending_prior, description "Official Scorer Ruling Pending", per GET /api/v1/eventTypes). (2) Official scoring changes — reclassifications after the fact (hit ↔ error, out ↔ hit, extra bases, RBI changes), detected by diffing each completed play's official classification between consecutive polls (the payload carries no change marker, so the initial call and the final ruling are known only from consecutive observations). (3) Pending → resolved — a pending ruling whose official outcome has since been published. Every row shows the official wording before and after (event code + the play description verbatim, RBI, out count, scores), the official score after the play, an attribution note (official scorer / Elias Sports Bureau / player–club review — see mlb.com/official-information/scoring-changes), and timestamps to the second. Persistence. This log survives a website refresh: it always writes to your browser (localStorage, keys mlbp.scoringlog.<date>, newest 14 dates kept, 500 rows per date), and — when the site is served with npm run serve — additionally to the server (/api/scoring-log → data/scoring-log-<date>.json, atomic writes, shared live across browsers over server-sent events). On static GitHub Pages there is no backend, so cross-browser sharing is not possible there; the per-browser log still survives refresh. A scoring change can only be logged when its initial call was observed before the change landed; the feed re-scans finals for 30 minutes after they end to catch late rulings. This page never predicts outcomes and never alters what it logs — irregularities (plays that vanish from the payload, edits without reclassification) remain visible on the replay feed as flagged rows.
